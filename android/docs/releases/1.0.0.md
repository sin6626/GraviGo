# GraviGo 1.0.0

GraviGo is an independent Android remote client for Antigravity, based on Jiuge (GHSaiMo)'s antigravity-mobile project.

## Included

- Native Android conversations with streaming replies, attachments, workspace references, and desktop commands.
- Plan and code-change review with positioned comments.
- Desktop account information, model selection and quota, and Simplified Chinese / English interfaces.
- Language changes update the current page without a black window or lost drafts.
- Windows x64 and macOS Apple Silicon / Intel gateways, matching source archive, full project/component notices, and SHA-256 checksums.

## Downloads and connection

Install `GraviGo-1.0.0.apk`. On Windows x64, install the latest stable gateway from PowerShell:

```powershell
irm https://raw.githubusercontent.com/sin6626/GraviGo/main/android/scripts/install-gateway.ps1 | iex
```

The installer downloads and verifies the gateway ZIP automatically, preserves its licenses, and prints the startup and pairing commands. Open Antigravity, change to the printed installation folder, and start `.\gravigo-gateway.exe run -port 58900`. Keep it running. In another terminal in that folder, run `.\gravigo-gateway.exe pair -port 58900` and pair the Android app. Manual download and extraction of the complete Windows gateway ZIP remain available.

On macOS, use Terminal; the installer selects Apple Silicon or Intel automatically:

```bash
curl -fsSL https://raw.githubusercontent.com/sin6626/GraviGo/main/android/scripts/install-gateway-macos.sh | bash
```

It verifies `SHA256SUMS-macos.txt` and prints the installation directory. Open Antigravity, change to that directory, and run `./gravigo-gateway run -port 58900`. In another terminal in that directory, run `./gravigo-gateway pair -port 58900`. Manual `.tar.gz` downloads remain available. The added Mac binaries use the same source commit identified by this release's `SOURCE.txt` and source archive.

A physical phone uses a reachable computer LAN address; the Android emulator uses `10.0.2.2:58900`. Pairing data belongs to each app package separately. Production is `io.github.sin6626.gravigo`; development builds ending in `.debug` and the earlier `com.antigravity.mobile` remain separate installations.

Check `SHA256SUMS.txt` for the APK, Windows gateway, and source archive, and `SHA256SUMS-macos.txt` for the added Mac packages. `SOURCE.txt` identifies the exact source commit. The source ZIP includes build instructions and the Gradle wrapper, and excludes local signing and pairing credentials.

## Validation and limits

The Android APK is signed with the backed-up GraviGo production certificate. Windows/Linux Go CI and Android unit tests, lint, and builds are required for this source commit. Emulator acceptance covers pairing, conversation reading, language transitions and app restart, with isolated protocol/UI tests for attachments and review comments.

Physical-device acceptance is intentionally deferred by the owner. Android versions below 13 have not been fully exercised on devices. Mac packages are tested and executed on native Apple Silicon and Intel CI runners; the complete connection flow against a real Mac Antigravity desktop is not yet accepted. Mac packages do not have Developer ID signatures or Apple notarization; see [Apple's instructions](https://support.apple.com/en-us/102445) if blocked. The Windows gateway is not Authenticode-signed.

The verified connection baseline is local networking. Automatic Cloudflare tunneling is now opt-in. The upstream public dispatcher/domain returned Cloudflare 1010/403 in this environment; public tunnels and remote push delivery are not claimed as validated 1.0.0 features. Voice transcription depends on the desktop account's permissions.
