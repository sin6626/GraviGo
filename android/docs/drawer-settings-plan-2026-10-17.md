# 抽屉底部入口：应用设置设计与实施计划

状态：方案已整理，尚未实施。当前任务只提交计划，不修改应用行为。

## 1. 结论

将右下角「人像」改为小号设置图标，点击打开「应用设置」底部面板。首版只做两个分区：**阅读偏好**、**关于与开源说明**。

保留左侧「配对」作为连接电脑的明确入口。右侧负责本机偏好和应用信息，两个入口各有职责。

不为人像临时编造账号、昵称、会员或个人资料。也不把配对、电脑状态、模型设置再复制进一个新的个人中心。

## 3. 首版内容与行为

### 阅读

一行「文件默认换行」，副说明「代码与纯文本适应屏幕宽度」，右侧为标准开关，默认开启。

- 本地立即保存，重启应用仍有效，无保存按钮和成功弹窗。
- 每次新打开阅读器时读取默认值；文件内换行图标只覆盖当前阅读器，不反向改全局偏好。
- Markdown 正文自然换行；其中的代码块跟随该文件的换行状态，沿用已有行为。
- 不改变文件内容、复制内容或消息里的代码块布局。
- 不改 `clear()` 的既有配对/应用清理语义；整体清理后该新增偏好恢复默认。

### 关于与开源说明

直接放在同一面板下半部，首版不再打开第二层弹窗或二级导航。

- 小号现有 App 图标、Multigravity 名称，以及从已安装包读取的真实版本号。
- 简短归属说明：基于九哥（GHSaiMo）的 antigravity-mobile v1.0.3，继续进行前端重做与配套网关扩展。
- 两个低强调文本入口：「本项目代码」「原项目」，分别通过系统浏览器打开现有项目链接。
- 本项目：`https://github.com/sin6626/AntigravityMobile-Android`；原项目：`https://github.com/GHSaiMo/antigravity-mobile`。
- 署名文本本地打包，打开面板不拉取 GitHub、版本服务或电脑状态；没有浏览器可处理链接时，只给一次简短反馈，保留当前页面。
- 使用仓库已有生成图标，不再生图，不添加装饰性插画。开源归属说明不冒充完整第三方许可证清单；已有许可证文件仍保留。

### 本轮暂不加入

完整深色主题、独立动效等级、账号头像编辑、缓存清理、更新检测、通知开关、权限自动批准和子代理展示。

这些项目中有的尚未完整接通、有的已有入口、有的会扩大行为或数据风险。首版不放灰色占位行或「敬请期待」。尤其不先做一个仅关闭部分动画的开关；本轮新动效直接遵循系统动画设置。

## 4. UI 规格

### 抽屉底部

- 左侧配对按钮位置和含义保持不变；右侧仅替换人像视觉及事件。
- 设置图标 21–22 dp，深灰色；48 × 48 dp 可点击区域，内部可用 36 dp 极浅灰圆底。
- 两侧控件垂直中心对齐；不新增「我的」文案、头像角标、渐变描边或呼吸光。
- 无障碍名称为「应用设置」。使用现有轻按压反馈，不旋转齿轮。

### 设置面板

- 白色背景、顶部 28 dp 圆角；复用 36 × 4 dp 灰色拖动柄。
- 标题「应用设置」17 sp、Semibold；右侧小关闭图标，实际触控区 48 dp。
- 水平边距 20–24 dp，分区间距 20–24 dp。每一分区不再套一张大圆角卡片。
- 设置行至少 56 dp；标题 15 sp，说明 12–13 sp。文字可增高换行，开关占独立空间，不挤压文字。
- 关于区图标 32 dp，与名称/版本同排；归属说明用次要文字色、正常行距。链接放在说明下方，低强调且各自有至少 48 dp 触控高度。
- 首版随内容自然撑高，常规字号预计约 340–420 dp；这是估算，不设固定百分比来凑半屏。大字号/横屏时最高占可用高度约 85%，内部可滚动，并避让系统导航栏。
- 不增加大面积品牌封面、欢迎语、用户积分、状态大卡片。

## 5. 动画与操作顺序

原则：只让必要的容器运动；文字、图标和开关保持原始尺寸。先做好一段连续转场，再填功能。

| 操作 | 预期表现 | 验收目标 |
| --- | --- | --- |
| 点击入口 | 按压立即可见，沿用 quietClickable；同一时间只处理一次打开 | 约 80–100 ms 按压反馈，无额外等待 |
| 抽屉到设置 | 清除搜索焦点，收起抽屉，再由页面打开原生底部面板；不同时保留两个遮罩 | 完整视觉衔接目标约 320–400 ms，不以单段时长冒充总时长 |
| 面板出现 | 沿用原生平移与遮罩；内容一次呈现，不逐行错峰、不缩放 | 面板自身目标约 180–220 ms，无过冲和重复淡入 |
| 关闭 | 下滑跟手；松手后按阈值回弹或退出；返回键、关闭图标、点遮罩一致 | 程序化退出目标约 160–200 ms |
| 切换偏好 | 只改变开关与颜色，整行、面板高度和阅读区不抖动 | 复用标准开关过渡，约 120–160 ms |
| 连点、打开后立即返回 | 不生成两个面板，不在关闭完成后被迟到协程重新打开 | 同一状态入口，可取消，返回最终状态正确 |
| 系统关闭动画 | 直接进入最终状态，拖拽手势仍可用 | 不额外等待任何固定 delay |

上述毫秒数是待实测目标，不声称当前 Material3 默认值已满足。实施第一步先测现有组件的真实总时长与可调范围；不复制私有动画实现，不为改时长引入框架。若默认流程拖尾，先解决打开/关闭调度与重复转场，再调整曲线。

### 必须避免的细节

- 不给原生 Sheet 再套 `contentEntrance`、整体 scale 或第二层滑入动画。
- 不让抽屉关闭、面板出现、内容出现各自再完整等待一次。
- 不修改聊天输入框宽度、位置或会话状态来配合设置页动画。
- 不把网络请求作为弹层显示条件，也不出现连接错误卡片或骨架屏。
- 关闭返回原来所在的聊天/项目页，保留当前会话、阅读位置和草稿；不自动再打开抽屉。
- 外部浏览器返回时不重播设置面板进场；后台中断后不突然弹出迟到的面板。

## 7. 实施顺序与验收

1. **先做入口和转场骨架**：只使用真实图标、标题和最终布局约束，录制抽屉→设置→关闭的原生过程；检查总时长、遮罩与输入框稳定性。此阶段不把占位面板作为正式交付。
2. **接通阅读偏好**：落地存储与阅读器默认值；测试默认开启、重启后保留、单文件覆盖不污染全局，以及复制原文不改变。
3. **补齐关于内容**：读真实安装版本，核对来源文字、现有图标和链接；在断网情况下打开面板，不能发起网关查询。
4. **整体验收后提交**：按功能提交中文 Conventional Commits；更新 Agent.md；交付实际 APK、静态截图和原生等速动效录屏，区分模拟器与真机结果。

验收必须包含：

- 320/360/412 dp 宽度、1.0/1.3/1.5 倍字号；标题、说明、开关、关闭按钮不重叠，不用减字号掩盖挤压。
- 断网、网关 502 与已连接状态下，设置内容一样可用；点击入口不产生子代理/电脑状态/会话刷新请求。
- 聊天、项目页、抽屉搜索键盘弹出时打开；返回保持原页面、原草稿和滚动位置。
- 快速连点、打开中返回、下滑到一半撤销、后台再回来；只有一个面板，焦点和遮罩正确恢复。
- 系统动画关闭与 TalkBack 操作；图标可朗读，开关有当前状态，所有入口至少 48 dp。
- 实际播放完整转场，再逐帧核对首帧/末帧、遮罩接续与文本尺寸；测试通过和静态截图不能替代动效验收。
